# Pixel Pet: 펫 수집 · 태양빛 · 저장 슬롯 설계

작성일 2026-11-11. 대상 프로젝트: `~/raea/games/projects/pixel-pet` (raea 게임, `edit.tsx` / `game.ts` / `art.ts` / `save.ts`).

표기: **(사용자)** 는 사용자가 정한 것, **✋** 는 설계자(Claude)가 정한 것이라 바꿔도 되는 것.

## 1. 왜 하는가

- 지금 펫은 "그냥 동그란 고양이"라 개성이 없다. 귀여운 캐릭터의 원칙을 적용한 새 펫들을 만든다. (사용자)
- 펫을 모으는 장기 목표를 만든다. 코인과 별개인 "태양빛"을 오래 플레이해서 모으고, 그걸로 새 펫을 산다. (사용자)
- 펫마다 능력과 도구가 달라서, 펫을 바꾸면 노는 감각이 달라진다. (사용자)

## 2. 목표 (사용자가 정한 것)

1. **시작 펫은 고양이.** 모찌룡·뭉게·우파는 사야만 쓸 수 있다.
2. **펫 구매는 홈 화면에서만.** 안 산 펫은 **실루엣만** 보인다. **능력은 대놓고** 보여준다. 사면 정체가 공개되는 연출이 나온다.
3. **펫은 태양빛으로 산다.** 태양빛은 **플레이 시간 20분마다 +1**. 플레이 화면을 켜 두고 **가만히 둔 시간도 포함**한다. 게임이 꺼져 있는 동안에는 쌓이지 않는다. 첫 새 펫까지 약 1시간(태양빛 3개).
4. **저장은 펫 단위, 저장 슬롯 최대 3개.** 새 펫으로 하려면 그 펫으로 새 게임을 시작한다.
5. **상점 도구는 펫마다 다르고 캐릭터에 맞는다.** 예: 고양이는 고양이 장난감, 꾹꾹이. 도구 레벨은 펫(슬롯)마다 따로.
6. **오프라인 보상 없음.** 꺼 둔 동안 코인도 태양빛도 안 쌓인다.
7. **귀여움 원칙 적용**: 큰 머리(2등신에 가까움), 과장된 특징 하나, 3/4 각도와 비대칭 포즈, 절제된 색(바탕 + 포인트 1개 + 볼 악센트), 하이라이트 있는 큰 눈, 짧은 팔다리와 가슴 앞에 모은 앞발. 참고 레퍼런스는 포켓몬 스프라이트지만 **원리만 가져오고 따라 그리지 않는다.**
8. **한국어와 영어를 둘 다 지원하고, 설정에서 고른다.** 게임 안의 모든 글자(버튼, 안내, 펫·도구·아이템 이름, 능력 문구)가 대상이다.
9. 이미 만든 것 유지: 자동 저장 ON/OFF, 효과음 ON/OFF, 💾 저장 후 "홈으로?" 확인, 드롭다운 바깥 클릭 시 닫힘, 입어보고 사기.

## 3. 비목표

- 펫별 다양한 모션(놀기, 잠자기 등). 이번 작업이 끝난 뒤 다음 단계에서 한다.
- 오프라인 보상.
- 배경음악.
- Windows / Intel Mac 지원.

## 4. 이러면 실패 (안티 목표)

- 기존 캐릭터(포켓몬 등)를 베낀 것처럼 보이는 디자인.
- 실루엣 상태에서 외형이 새어 나가는 것. 색, 아이콘, 미리보기에서 정체가 드러나면 안 된다. 이름도 "???"로 가린다 ✋.
- 홈 화면에 있거나 게임이 꺼져 있는데 태양빛이 쌓이는 것.
- 한 언어에서만 글자가 칸을 넘치거나 겹치는 것.
- 한 슬롯의 진행(코인, 도구, 옷)이 다른 슬롯으로 새는 것.
- 지금 쓰고 있는 사용자의 저장 데이터가 사라지거나 깨지는 것.
- 렌더 결과가 실행마다 달라지는 것. 지금처럼 게임 상태는 순수 fold여야 한다.

## 5. 데이터와 저장

### 무엇이 어디에 속하나

- **계정 공용** ✋: 태양빛 개수, 다음 태양빛까지 쌓인 플레이 시간, 보유 펫 목록, 설정(자동 저장, 효과음).
  - 태양빛은 어느 슬롯으로 플레이하든 같은 통에 쌓인다 ✋.
- **슬롯 1~3 각각**: 펫 종류, 코인, 누적 코인, 그 펫의 도구 2종 레벨, 보유·착용 꾸미기, 플레이 시간 ✋.

### 저장 방식

- 지금처럼 `~/Library/Application Support/pixel-pet-save.db` 의 SQLite `save` 테이블에, slot 키를 나눠 저장한다 ✋: `account`, `slot1`, `slot2`, `slot3`, `settings`.
- **기존 저장 이전** ✋: 지금 `main` 키에 있는 진행(고양이)은 처음 실행될 때 `slot1` 의 고양이 슬롯으로 옮긴다. 기존 도구 레벨 `pickaxe`(초당) → 고양이 초당 도구, `gloves`(탭) → 고양이 탭 도구로 옮긴다. 기존 꾸미기 보유·착용은 그대로 간다.
- 자동 저장 ON이면 지금 규칙 그대로(10초마다, 구매·업그레이드·착용 때).
- **태양빛은 얻는 순간 바로 저장한다** (사용자). 슬롯 저장이나 자동 저장 설정과 상관없다.
- 다음 태양빛까지 쌓인 시간도 자동 저장 설정과 상관없이 10초마다, 그리고 홈으로 갈 때 계정에 저장한다 ✋. 그래야 15분씩 끊어 해도 시간이 이어서 쌓인다.
- 홈 화면의 펫 구매도 즉시 계정에 저장한다 ✋.
- 저장 읽기는 지금처럼 첫 live 프레임에만, 쓰기는 view의 effect에서. 렌더(비라이브)는 디스크를 읽지도 쓰지도 않는다.

## 6. 화면

### 홈 화면

- 위 띠에 제목 "PIXEL PET", 그리고 **태양빛 개수** ✋.
- **슬롯 3칸**을 카드로 보여준다 ✋. 각 카드에 펫 얼굴, 코인, 스타일 수, 플레이 시간. 빈 슬롯은 "NEW GAME".
  - 찬 슬롯 클릭 → 그 슬롯으로 이어 하기.
  - 빈 슬롯 클릭 → **보유한 펫 중에서 고르기** → 새 게임.
  - **슬롯마다 따로 있는 삭제 버튼**으로 지운다 (사용자). 누르면 "이 슬롯을 지울까요?" 확인 창이 뜨고 [삭제] / [취소]를 고른다 ✋. 지우면 빈 슬롯이 된다.
- **PETS 버튼** → 펫 상점(4칸 카드).
  - 안 산 펫: 검은 실루엣, 이름 "???", 능력 문구(대놓고), 태양빛 가격, 살 수 있으면 BUY.
  - 산 펫: 실제 모습과 이름, 능력, "OWNED".
  - **구매 연출** ✋: 실루엣이 빛나며 색이 채워지고, 펫이 한 번 통통 뛰고, 이름이 뜨고, 팡파레.
- ⚙ 설정 버튼 그대로.
- 같은 펫으로 슬롯을 여러 개 만들어도 된다 ✋.

### 플레이 화면

- 위 HUD에 **태양빛 칸**을 추가한다 ✋. 태양빛 타이머는 플레이 화면에 있는 동안 입력이 없어도 흐른다 (사용자). 개수와 다음 태양빛까지 진행 막대.
- **하늘이 20분 주기로 바뀐다** ✋. 아침 → 낮 → 노을 → 밤, 해가 다시 뜰 때 "태양빛 +1" 연출. 지금의 노을·밤 하늘은 이 주기의 일부가 된다.
- **SHOP**: 지금 펫의 도구 2종(초당 코인 도구, 탭 코인 도구). 이름·아이콘·수치 문구가 펫마다 다르다.
- **CLOSET**: 모자·옷·액세서리 7종 ✋. 목록은 모든 펫 공용, 그림은 펫마다 체형에 맞게 다시 그린다. 보유·착용은 슬롯마다 따로.
- 💾, ⚙, 저장 후 홈 확인 창은 그대로. 홈으로 가면 슬롯 화면으로 간다.
- 펫을 플레이 중에 바꾸는 기능은 없다. 펫은 슬롯에 묶인다. (사용자: 새 펫은 새 게임)

### 설정 창

- 지금의 자동 저장, 효과음 스위치 아래에 **언어(LANGUAGE) 선택**을 추가한다: 한국어 / ENGLISH. 이 값도 설정 슬롯에 저장된다.
- 처음 기본 언어는 한국어 ✋.

## 7. 언어

- 모든 화면 문자열을 한 곳(문자열 표, 키 → { ko, en })에 모은다 ✋. 화면은 키로만 글자를 꺼낸다.
- **영어**는 지금의 5×7 픽셀 폰트 그대로.
- **한국어**는 Mac 기본 한글 폰트(Apple SD Gothic Neo, 굵게)에 지금과 같은 진한 그림자를 주어 쓴다 ✋. 이 폰트는 모든 Mac에 있어서 추출한 앱에서도 나온다. 사용자가 한글 픽셀 폰트 파일(예: 갈무리, OFL)을 주면 그 폰트로 바꾼다. 다운로드는 이쪽에서 막혀 있다.
- 두 언어 모두 글자가 칸을 넘치지 않게 칸 크기를 정한다(한글은 글자 수가 적고 폭이 넓다).
- 영어 이름 ✋: 고양이 KITTY, 우파 UPA, 뭉게 MUNGGE, 모찌룡 MOCHIRYU / 장난감 낚싯대 TEASER WAND, 꾹꾹이 KNEAD PAWS, 물방울 펌프 BUBBLE PUMP, 지느러미 박수 FIN CLAP, 구름 방석 CLOUD CUSHION, 몽글 박치기 FLUFF BONK, 보물 더미 TREASURE PILE, 날갯짓 WING FLAP. 꾸미기 7종의 한국어 이름도 붙인다(리본, 야구모자, 왕관, 줄무늬 티, 영웅 망토, 선글라스, 목도리).

## 8. 펫 (✋ 초안 수치)

| 펫 | 얻는 법 | 능력 (그대로 보여줄 문구) | 초당 코인 도구 | 탭 코인 도구 |
|---|---|---|---|---|
| 고양이 | 처음부터 | 탭 코인 +50% | 장난감 낚싯대 | 꾹꾹이 |
| 우파 (우파루파) | 태양빛 3 | 탭 10번 중 1번 대박 ×5 | 물방울 펌프 | 지느러미 박수 |
| 뭉게 (구름 아기 양) | 태양빛 5 | 초당 코인 +50% | 구름 방석 | 몽글 박치기 |
| 모찌룡 (아기 용) | 태양빛 8 | 모든 코인 +25% | 보물 더미 | 날갯짓 |

- 가격 순서는 사용자의 귀여움 순위(모찌룡 > 뭉게 > 우파)를 반대로 둬서, 제일 좋아하는 모찌룡이 최종 목표가 되게 했다 ✋. 전부 모으려면 플레이 약 5시간 20분.
- 도구 수치 곡선은 지금과 같다 ✋. 초당 도구 1, 2, 4, 7, 11…/초(비용 20×1.8^레벨), 탭 도구 1, 2, 3…/탭(비용 15×1.7^레벨). 능력 보너스는 그 위에 곱한다.
- 우파의 대박 탭은 프레임 번호로 정한 결정적 난수로 고른다(렌더·재생이 같아야 한다).
- 고양이도 같은 원칙으로 다시 그린다 ✋. 사용자의 출발점이 "고양이를 더 귀엽게"였기 때문이다.

## 9. 그림

- 시작점: 콘셉트 시트 `out/concepts-v2.png`(모찌룡·우파·뭉게)와 그 코드 `out/concepts.tsx`. 사용자가 셋 다 좋다고 했다.
- 펫마다 필요한 그림 ✋: 숨쉬기 3포즈 + 탭 찌그러짐 1포즈, 눈 3종(뜸·깜빡·웃음), 실루엣(같은 모양을 한 색으로), 홈 카드용 얼굴.
- 꾸미기 7종 × 펫 4마리 = 28개 착용 그림. 펫마다 앵커(머리 위, 눈, 목, 몸통)를 정해서 위치와 크기를 맞춘다 ✋.
- 펫 도구 8개 아이콘(펫 4 × 도구 2).
- 지금 게임은 32×28 셀(셀당 13 필드 단위)로 펫을 그린다. 새 펫은 콘셉트처럼 40×40 셀로 그리고 화면 크기에 맞게 셀 크기를 정한다 ✋.

## 10. 지켜야 할 제약

- raea 게임 구조: `useGameState(initial, step)` 순수 fold, `useGameEvents` 로 효과음, 디스크는 첫 live 프레임에 읽고 effect에서 쓴다.
- 앱 추출(`raea export-game`): 효과음·폰트 같은 파일 경로는 코드에 문자열 그대로 써야 앱에 들어간다.
- 데모(아무도 조작하지 않을 때의 자동 플레이)는 렌더용으로 계속 돌아가야 한다. 새 흐름(슬롯 선택 → 새 게임)에 맞게 고친다.
- `playtest` export 를 유지한다(키보드로도 모든 흐름을 할 수 있어야 한다).
